# Contributing to Spearhead Platform

Thank you for your interest in contributing.

We welcome:

- Bug fixes
- Documentation
- Features
- Plugins
- Performance improvements
- Testing
- Infrastructure

---

## Development

Clone the repository

Install dependencies

```bash
pnpm install
```

Start development

```bash
pnpm dev
```

Run tests

```bash
pnpm test
```

Lint

```bash
pnpm lint
```

---

## Pull Requests

Before submitting a PR:

- Tests pass
- Lint passes
- Documentation updated
- CHANGELOG updated (if applicable)

---

## Commit Messages

Use Conventional Commits.

Examples

```
feat(radio): add autoplay

fix(discord): reconnect after disconnect

docs(api): update examples
```

---

## Branches

Feature work:

feature/my-feature

Bug fixes:

fix/my-bug

Documentation:

docs/update-readme

---

## Questions

Open a GitHub Discussion before implementing large architectural changes.
