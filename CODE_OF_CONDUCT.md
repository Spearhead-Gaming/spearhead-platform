# Code of Conduct

## Our Pledge

The Spearhead Platform community is committed to creating a welcoming,
professional, and inclusive environment for everyone.

We believe that respectful collaboration produces better software.

Regardless of age, experience level, disability, ethnicity, gender identity,
sexual orientation, nationality, religion, or background, every contributor
deserves to be treated with respect.

---

## Expected Behavior

We encourage contributors to:

- Be respectful and professional.
- Welcome constructive feedback.
- Assume positive intent.
- Help new contributors learn.
- Focus discussions on technical merit.
- Respect project decisions.

---

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or discrimination
- Personal attacks
- Hate speech
- Threats or intimidation
- Deliberately disruptive behavior
- Publishing private information
- Spam or malicious contributions

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Violations may result in:

- Warning
- Temporary suspension
- Permanent removal from the community

---

## Reporting

Please report violations privately through GitHub Security Advisories or by contacting the maintainers.
