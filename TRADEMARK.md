# Introduction

The **Spearhead Platform** is open-source software licensed under the Apache License 2.0.

While the source code is available under that license, the names, logos, artwork, branding, and other identifying assets associated with the Spearhead community are **not** licensed under Apache 2.0.

This policy explains what you may and may not do with the Spearhead trademarks and branding.

# What You May Do

You are welcome to:

- Fork the source code.
- Modify the source code.
- Distribute the source code.
- Build your own applications using the source code.
- Develop plugins and extensions.
- Reference the project by name when discussing or contributing to it.
- State that your software is "based on the Spearhead Platform."

---

# What You May Not Do

Without prior written permission, you may not:

- Present a modified version as the official Spearhead Platform.
- Use the Spearhead name in a way that suggests endorsement.
- Use Spearhead Gaming logos.
- Use the official 83.1 MISFIT FM branding.
- Use official podcast artwork.
- Use official banners.
- Use official mascots.
- Repackage the software using Spearhead branding.
- Create confusingly similar branding.
- Impersonate the Spearhead community.

---

# Forks

Forks are encouraged.

However, if you distribute a modified version, you must:

- Change the application's name.
- Remove official logos.
- Remove official artwork unless separately licensed.
- Clearly indicate that your version is an unofficial fork.

Example:

✔ Good

"MyRadio Platform (based on Spearhead Platform)"

✘ Not Allowed

"Official Spearhead Platform Community Edition"

They may not imply official endorsement unless permission has been granted.
